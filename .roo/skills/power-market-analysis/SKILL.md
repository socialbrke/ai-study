# 何时使用
当电力交易人员需要制定交易策略前，使用此技能进行市场分析。

# 何时不使用
- 当需要执行实际交易操作时（应使用交易执行技能）
- 当需要分析其他能源市场（如石油、天然气）时

# 输入要求
用户应提供以下信息（如可用）：
- 当前市场供需数据
- 历史价格数据
- 天气预报（特别是影响电力需求的温度等因素）
- 政策变化或市场公告

# 工作流程
1. **市场供需分析**  
   使用 [references/market-template.csv](references/market-template.csv) 模板收集数据  
   分析当前供需平衡情况
   
2. **价格趋势预测**  
   使用 [scripts/price-forecast.py](scripts/price-forecast.py) 进行短期价格预测  
   识别关键支撑/阻力位
   
3. **风险评估**  
   评估天气和政策风险因素  
   计算潜在波动率
   
4. **生成建议**  
   综合以上分析生成操作建议：  
   - 保守策略（低风险）  
   - 平衡策略（中等风险）  
   - 激进策略（高风险）

# 示例分析
```
用户输入：
- 当前需求：12000MW
- 当前供应：11500MW
- 天气预报：未来3天气温升高

分析结果：
供需缺口500MW，气温升高将增加制冷需求，预计价格上行。

建议：
- 短期：买入远期合约
- 风险控制：设置5%止损位
```

# 注意事项
- 市场变化快速，建议在交易前重新运行分析
- 本建议仅供参考，实际交易需结合个人风险承受能力
